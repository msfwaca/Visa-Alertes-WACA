# User guide

## Navigate

Use the left menu: **Accueil**, **Visas**, **Requêtes**, **Personnel** (and **Admin** for authorised users). The ☰ icon collapses the menu.

## Read the dashboard

Blue = active, orange = expiring soon, red = expired. Click a tile to open the matching list.

## Add or edit a visa

1. Open **Visas** → **New** (or click a row).
2. Fill staff, type, country, visa number, dates.
3. **Save**. Required fields show an error until filled; a visa number can only be used once.

## Track a visa request

1. Open **Requêtes** → **New**.
2. Choose staff, type, destination, date, status, officer, priority. The request ID is created for you.
3. Update the status and dates as the request progresses.
4. When it is **Approved**, fill the visa number and dates and click **Convertir en visa**. The visa is created and the request moves to *Passeport rendu*.

## Manage staff

**Personnel** → add or edit a person. Name, e-mail, nationality and department are required.

## Something went wrong?

A red message means the action failed: try again, then contact the Systems Implementation Support team.
